# Glossary (Spanish domain term -> English code term)

The code is in English but the domain is Spanish. Use these names so everyone says the same thing.

| Spanish term | In the code | Notes |
|---|---|---|
| ayuda / subvención | `aid` | Public aid or subsidy |
| explotación (agraria o ganadera) | `farm` | |
| perfil de la explotación | `FarmProfile` / `profile` | What the user tells us about their farm |
| comunidad autónoma | `region` | Values stay in Spanish ("Aragón", "Castilla y León"...) |
| tipo de ganado | `livestock_type` | `cattle`, `sheep`, `goat`, `pig`, `equine`, `poultry`, `bees`, `other` |
| sistema de producción | `production_system` | `extensive`, `intensive`, `organic`, `mixed` |
| forma jurídica | `legal_form` | `individual`, `limited_company`, `corporation`, `cooperative`, `joint_property`, `other` |
| edad del titular | `holder_age` | |
| agricultor activo | `active_farmer` | Common CAP requirement |
| REGA | `rega_registered` | Registro General de Explotaciones Ganaderas |
| objetivo | `goal` | `income`, `start_up`, `modernization`, `insurance`, `animal_health`, `organic`, `other` |
| PAC | CAP | Common Agricultural Policy |
| PEPAC | CAP Strategic Plan | Spain's plan for 2023-2027 |
| FEGA | FEGA | Fondo Español de Garantía Agraria (CAP payments agency) |
| BDNS | BDNS | Base de Datos Nacional de Subvenciones |
| ayuda asociada | `cap_coupled` | Coupled support, by livestock type |
| ecorregímenes | `eco_scheme` | |
| requisito | `requirement` | Statuses: `met`, `not_met`, `unknown`; only verified, cited rules can be definitive |
| elegibilidad | eligibility | Overall: `met`, `not_met`, `unknown`; an award is never guaranteed |
| fiabilidad | `reliability` | `verified`, `extracted`, `metadata_only` |
| bases reguladoras | regulatory rules | Official rules of each aid call |
| ficha (de una ayuda) | aid record | One entry in `aids.json` |
| jornada del reto | event day | |
