# National product roadmap

This is the working roadmap for development. The product scope is all of Spain, for agricultural, livestock and mixed farms. BDNS/SNPSAP is the primary discovery source. Aragón is an end-to-end validation case, not the product boundary.

## Phase 0 — Scope and launch criteria

### Agreed and done

- [x] Set nationwide scope: national, autonomous-community, autonomous-city and relevant local aid.
- [x] Include agriculture, livestock and mixed holdings; all profile fields remain optional.
- [x] Choose BDNS/SNPSAP as primary discovery source, with links to official bases and documents.
- [x] Define reliability states and prevent unverified records from producing definitive eligibility outcomes.
- [x] Use Aragón as an initial validation case without limiting national coverage.
- [x] Define the territory and category coverage matrix: all 17 autonomous communities, 2 autonomous cities, national schemes, and relevant provinces/localities; track crop, livestock and mixed-farm aid categories and campaign.
- [x] Define the public coverage labels: not checked, indexed, details extracted, and verified; show the last checked date.
- [x] Set measurable MVP launch criteria: every territory has been queried in BDNS; discovered relevant calls are indexed or explicitly marked out of scope; displayed status and freshness are clear; no extracted/unverified aid can return definitive eligibility.
- [x] Defer assigning a data steward until pre-launch operations. Set the refresh cadence after the BDNS access guidance and API probe; keep it configurable until then.

**Phase 0 exit:** scope, coverage measurement, user-facing coverage labels and launch gate are agreed. Assigning the data steward is deferred until pre-launch operations, as agreed.
